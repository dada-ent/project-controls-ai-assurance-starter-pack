### RELEASE NOTES — READY TO PASTE

DADA's **Project Controls AI Assurance Starter Pack v1.0** is a free, reusable toolkit for teams using AI to assemble, test and route Project Controls evidence while retaining accountable human authority.

**Included in this release:**

• 17 editable templates across four controlled stages;  
• blank reusable versions plus completed fictional CE-018 examples;  
• a Power BI assurance dashboard;  
• four Word decision-readiness reports;  
• four Excel scorecards; and  
• the CaSA presentation explaining the control method.

The same pattern can be configured for **cost, schedule, risk, change, reporting, Stage Gate assurance and Handover to Maintenance**.

**Control boundary:** AI can extract, compare, reconcile, cite, flag and prepare review material. The named human retains the decision.

Start with one bounded use case, approved evidence, defined tests and a named decision route.

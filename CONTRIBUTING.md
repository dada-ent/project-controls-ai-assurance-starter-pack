# CONTRIBUTING

This repository is primarily a reusable Project Controls toolkit rather than a software codebase.

## REPORT A PROBLEM

Use the **Template / output issue** GitHub issue template. Identify the file, version, cell/section and expected correction. Do not upload confidential project evidence.

## PROPOSE A NEW USE CASE

Use the **New Project Controls use case** issue template. Describe the decision, approved source records, tests, accountable owner and the point at which AI must stop or escalate.

Useful candidate extensions include cost assurance, schedule assurance, risk reporting, Stage Gate preparation and Handover to Maintenance.

## PULL REQUESTS

Keep changes bounded and evidence-led. Do not remove human approval controls or turn a demonstration control into an assertion of contractual or legal compliance.
